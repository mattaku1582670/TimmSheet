# 分割回数別テーブルビュー 設計ドキュメント

**日付:** 2026-06-11  
**対象:** TimmSheet — マトリクスタブへの分割回数別ビュー追加

---

## 概要

現在の「マトリクス」タブ（全分割回数×全臓器のクロス表）に加えて、特定の分割回数を選択して臓器ごとの線量制約を一覧できる「分割回数別」ビューをマトリクスタブ内に追加する。Timmerman原論文のテーブル形式に近い参照ビュー。

## テーブル仕様

### 列定義

| 列見出し | データソース | null時の表示 |
|---|---|---|
| 臓器名 | `organJa`（空なら`organEn`） | — |
| Volume | `fr[n].volume` | — |
| Volume max | `fr[n].volMax` | — |
| Max point dose | `fr[n].maxPoint` | — |
| Endpoint | `endpointJa`（空なら`endpointEn`） | — |

- Contouring instructions列は含めない

### セクション分け

- Serial OARs（`type === "serial"`）を上、Parallel OARs（`type === "parallel"`）を下に表示
- 各セクションに見出し行を設ける

### 複数段階の値

`volume` / `volMax` が `" / "` 区切りで複数段階を含む場合（例: `"<0.2 cm³ / 1/3 organ / 2/3 organ"`）、セル内で各段階を改行して表示する。Volume と Volume max は同じ段階数であるため、行数を合わせて対応させる。

### 分割回数セレクター

- ボタン形式: `1fr` `2fr` `3fr` `4fr` `5fr` `8fr` `10fr` `15fr` `20fr` `30fr`
- 初期選択: `1fr`
- 選択中のボタンにはアクティブスタイルを適用

## フィルタリング

既存の検索インプット（臓器名検索）および Serial/Parallel フィルタボタンは分割回数別ビューでも動作する。

---

## 実装方針

- 新規ファイル `js/view-fraction.js` を追加し、`TT.renderFraction(container)` を実装
- `index.html` に `<script src="js/view-fraction.js">` を追加
- `js/app.js` に表示モード切り替えロジック（`matrix` / `fraction`）を追加
- `css/styles.css` にトグルボタンおよび分割回数別テーブルのスタイルを追加
- データアクセスは既存の `TT.getOrgans()` / `TT.FRACTIONS` を使用

- Contouring instructions列
